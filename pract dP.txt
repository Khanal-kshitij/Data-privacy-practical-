Practical 1: Caesar Cipher (Encryption and Decryption)

Aim: Write a Python program to perform encryption and decryption using the Caesar substitution cipher.

Program:

def encrypt(text, shift):
    result = ""

    for char in text:
        if char.isupper():
            result += chr((ord(char) - 65 + shift) % 26 + 65)
        elif char.islower():
            result += chr((ord(char) - 97 + shift) % 26 + 97)
        else:
            result += char

    return result


def decrypt(text, shift):
    return encrypt(text, -shift)


message = input("Enter message: ")
shift = int(input("Enter shift value: "))

encrypted = encrypt(message, shift)
decrypted = decrypt(encrypted, shift)

print("Encrypted Message:", encrypted)
print("Decrypted Message:", decrypted)

Practical 3: SHA-256 Password Hashing

Aim: Write a Python program that takes a password as input and returns its SHA-256 hashed representation as a hexadecimal string.

Program:

import hashlib

def hash_password(password):
    result = hashlib.sha256(password.encode())
    return result.hexdigest()


password = input("Enter password: ")

hashed_password = hash_password(password)

print("Original Password:", password)
print("SHA-256 Hash:", hashed_password)

Output (illustrative):

SHA-256 Hash:
<64-character hexadecimal hash>

Result: Successfully generated the SHA-256 hash of a password.

Note: SHA-256 is a one-way hashing algorithm, not encryption. Real password storage should use Argon2id, bcrypt or scrypt with unique salts rather than plain SHA-256.

import hashlib
import requests

def check_password(password):
    sha1_hash = hashlib.sha1(
        password.encode("utf-8")
    ).hexdigest().upper()

    prefix = sha1_hash[:5]
    suffix = sha1_hash[5:]

    url = "https://api.pwnedpasswords.com/range/" + prefix

Program:

import random
import secrets
import string

def generate_password(filename):
    with open(filename, "r") as file:
        words = [word.strip() for word in file
                 if word.strip()]

    selected_words = [
        secrets.choice(words) for _ in range(3)
    ]

    number = secrets.randbelow(1000)
    symbol = secrets.choice("!@#$%&*")

    password = (
        "-".join(selected_words)
        + str(number)
        + symbol
    )

    return password


password = generate_password("words.txt")

print("Generated Password:", password)

Practical 6: Brute-Force Attack Simulation

Aim: Write a Python program that simulates a brute-force attack on a password by trying all possible character combinations.

Program:

import itertools
import string

def brute_force(target):
    characters = string.ascii_lowercase + string.digits

    attempts = 0

    for length in range(1, len(target) + 1):

        for combination in itertools.product(
            characters, repeat=length
        ):

            guess = ''.join(combination)
            attempts += 1

            if guess == target:
                print("Password Found:", guess)
                print("Total Attempts:", attempts)
                return

    print("Password Not Found")


password = input(
    "Enter a small test password (lowercase and digits): "
)

brute_force(password)

Output:
Enter a small test password (lowercase and digits): ab

Password Found: ab
Total Attempts: 12

Result: Successfully simulated a brute-force attack by testing different character combinations until the password was found.

Note: This is a small educational demonstration. Brute-force attacks become computationally expensive as password length and character variety increase.

Practical 9: Data Protection Regulations and Compliance Plan

Aim: Study the requirements of data protection regulations and develop a plan for ensuring compliance.

For India, the relevant legislation is the Digital Personal Data Protection Act, 2023 (DPDP Act).

Important requirements:

    Notice: Inform individuals about the personal data being collected and its purpose.

    Consent: Obtain valid consent where consent is the applicable lawful basis.

    Data minimization: Collect only the data necessary for the specified purpose.

    Purpose limitation: Use personal data only for permitted purposes.

    Data security: Apply reasonable security safeguards.

    Data breach notification: Follow applicable breach notification requirements.

    Data principal rights: Provide mechanisms for exercising applicable rights.

    Data deletion: Erase personal data when the purpose is no longer served, subject to legal retention requirements.

    Grievance redressal: Establish a mechanism for handling complaints.

    Children's data: Follow the additional requirements applicable to children's personal data.

Practical 10: Ethical Considerations in Data Privacy

Aim: Study ethical considerations in data privacy, including the balance between privacy and security, the impact of data collection on marginalized communities, and the role of data ethics in technology development.
1. Balance between Privacy and Security

    Privacy protects an individual's personal information.

    Security protects information against unauthorized access.

    Organizations should maintain security without unnecessarily violating individual privacy.

Example: CCTV cameras improve security, but excessive surveillance can affect people's privacy.
2. Impact of Data Collection on Marginalized Communities

    Excessive data collection can disproportionately affect vulnerable communities.

    Biased algorithms can discriminate against certain groups.

    Lack of digital literacy can prevent people from understanding consent.

    Incorrect personal data can lead to unfair decisions.

Example: An AI-based loan approval system may reject applicants unfairly because of biased training data.
3. Role of Data Ethics in Technology Development

Data ethics means using data responsibly, fairly and transparently.
